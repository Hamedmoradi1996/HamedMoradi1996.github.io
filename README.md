# Building Science Academic Portfolio — GitHub Pages

A responsive, minimalist academic portfolio starter site for a building-science researcher. It uses plain HTML, CSS, and JavaScript, so no build tools or paid hosting are required.

## Files
- `index.html` — page content and sections
- `assets/style.css` — responsive styling
- `assets/script.js` — mobile navigation and current year

## Publish for free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload all files and folders in this ZIP to the repository root. Make sure `index.html` is at the top level.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for deployment, then visit `https://YOUR-USERNAME.github.io`.

Official instructions: https://docs.github.com/en/pages/quickstart

## Before publishing — important edits
Search `index.html` for:
- `Hamed Moradi` — update if you want a different display name.
- `YOUR.EMAIL@EXAMPLE.COM` — replace with your professional email.
- `Add your profile URL` — add your LinkedIn profile.
- `Add your researcher profile` — add your Google Scholar profile.
- Publication entries — confirm the author order, year, volume, pages, DOI, and current publication status.
- Project descriptions — ensure they accurately reflect your own work and contributions.

Add your CV as `assets/cv.pdf` to make the CV link work. If you prefer not to include a CV yet, remove that link from the contact section.

## Add your own figures
The current diagrams are original inline SVG illustrations and are labelled as schematic. Replace them with your own publication-quality figures only when you have permission to share them. Avoid uploading confidential data, unpublished collaborator material, or copyrighted figures without permission.

## Privacy and maintenance
GitHub Pages websites are public. Do not upload passport or visa documents, private contact details, confidential datasets, or anything you would not want indexed by search engines. Use a professional email address if you want to publish an email link.
